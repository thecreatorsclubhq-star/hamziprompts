# Hamzi Prompts

AI video prompts and learning resources for creators making TikTok videos, Instagram Reels and YouTube Shorts.

[Visit Hamzi Prompts](https://hamziprompts.com) · [Browse prompts](https://hamziprompts.com/browse) · [Academy](https://lms.hamziprompts.com)

## What we do

Starting with a blank prompt takes time. Hamzi Prompts gives creators a place to find a direction, pick a prompt and take it into their preferred AI video tool.

The live platform includes a prompt library with free and premium access, categories for different video styles, a community for sharing results, and an academy with lessons and creator workflows.

This repository holds public project documentation and the roadmap. The website is the working product. Website source code and the premium prompt collection are maintained separately.

## How it works

1. Browse the library by category or video idea.
2. Choose a prompt and adapt it to your own scene.
3. Use the prompt in your AI video tool.
4. Share the result with the community or work through the academy lessons.

## Planned Claude integration

We plan to add the Claude API to help creators improve prompts and turn ideas into scene-by-scene storyboards. These features are in planning; they are not available in the current library.

The first two workflows we want to build are:

- **Prompt refinement:** take a creator's draft and help clarify the subject, action, camera direction and visual style.
- **Storyboard drafts:** break a short video idea into scenes with a prompt for each scene, which the creator can edit before using it.

Claude would handle text and planning. Video generation would remain with the creator's chosen video tool.
